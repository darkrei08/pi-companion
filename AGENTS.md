## Code graph (graphify)

This repository has a code graph under `graphify-out/`, generated by `graphify`.

- Full rebuild: `graphify extract . --code-only`.
- Add this repository to the cross-repo graph: `graphify global add graphify-out/graph.json`.
- `graphify-out/` is build output. Keep it gitignored and never commit it.
